PROJECT · P.01 — HIGHWAY INFRASTRUCTURE

Highway interchange model

Year2024
RoleBIM Coordinator
ToolsRevit · Navisworks · Civil 3D
DisciplinesAlignment · Structure · Drainage

A multi-level interchange is where every discipline meets — literally. The road alignment from Civil 3D, bridge structure from Revit, and the drainage network threading between pile caps — all living inside a single linked model.

My job was the joints: a shared coordinate system for the whole project, drawing naming rules, a weekly clash-review cycle, and a decision log so no conflict ever had to be solved twice.

01Single linked model
-70%Clash-review time
100%IFC handover per BEP

Outcomes

  • One linked model covering alignment, structure and drainage — every party working on the same coordinate base.
  • Clash-review cycle cut from weeks to days via automated clash tests ahead of every coordination meeting.
  • Clean IFC handover matching the project BEP — the contractor could start on the model immediately.
