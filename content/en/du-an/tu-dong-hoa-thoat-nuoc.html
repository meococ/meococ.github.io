PROJECT · P.03 — AUTOMATION · BIM

Drainage network automation

Year2023
RoleAutomation · BIM
ToolsDynamo · Python · Civil 3D
InputNetwork spreadsheet

Modeling drainage is honest, repetitive work: manholes, pipes, invert levels — over and over for every design revision. I wrote Dynamo + Python scripts that read the network straight from the engineer's spreadsheet and place it into the model.

When the design changes — and it always changes — we re-run the script instead of remodeling for a week. The model always matches the spreadsheet, and the spreadsheet stays the single source of truth.

-80%Repetitive modeling time
84Manholes placed automatically
01Update run for every drawing

Outcomes

  • Repetitive modeling time cut to a fraction — effort moved to checking instead of placing.
  • The spreadsheet drives the model: fix the numbers, re-run the script, model and labels update themselves.
  • Scripts shipped fully documented so teammates can run them without me in the room.
