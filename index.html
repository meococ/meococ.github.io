✳Case study

Highway interchange model

Year2024
RoleBIM Coordinator
ToolsRevit · Navisworks · Civil 3D

A multi-level interchange is where every discipline meets — literally. Alignment from Civil 3D, bridge structures from Revit, and a drainage network threading between pile caps, all in one federated model.

My job was the seams: shared coordinates, naming conventions, a weekly clash cycle and a decision log so no conflict had to be resolved twice.

✳What came out of it
  • One federated model across alignment, structures and drainage
  • Clash review cycle shortened from weeks to days
  • Clean IFC handover aligned with the project BEP

Metro depot coordination

Year2023
RoleBIM Coordinator
ToolsNavisworks · BIM 360 · QA/QC

A depot packs workshops, tracks and MEP into a tight footprint. We ran a structured clash matrix in Navisworks — discipline pairs, tolerances and owners agreed up front.

Issues lived in BIM 360 with due dates and screenshots, so coordination meetings reviewed decisions instead of hunting for problems.

✳What came out of it
  • Hundreds of clashes closed before issue-for-construction
  • A clash matrix the team still reuses on new jobs
  • Coordination meetings that end on time

✳Case study

Drainage network automation

Year2023
RoleAutomation · BIM
ToolsDynamo · Python · Civil 3D

Drainage modeling is honest, repetitive work: manholes, pipes, invert levels, again and again. I wrote Dynamo + Python scripts that read the network from spreadsheets and place it in the model.

When the design changed — and it always changes — we re-ran the script instead of re-modeling the week.

✳What came out of it
  • Repetitive modeling time cut to a fraction
  • Spreadsheet-driven updates: model once, update everywhere
  • Scripts documented so teammates run them without me
